# Specialized Projects Group — the shelf

Tools we built to run our own operation, published as-is under MIT. Each one is a working example of a department on
[the portfolio](https://www.specializedprojectsgroup.com/portfolio). Download it, run it, and if you want it built for your
plant, that is what [the Teardown](https://www.specializedprojectsgroup.com/teardown) is for.

**This organization is public by policy.** It cannot hold private repositories. Active client programs live elsewhere
and never appear here.

## What goes on the shelf

- Built on our own time, for our own operation first.
- `LICENSE` (MIT), a README with one screenshot, the problem it was built for, how to run it, and a link back to the
  department it demonstrates.
- Code and example configuration only. No data files, no transcripts, no client names, sites, people or internal
  codenames — in code, comments, sample data, screenshots or commit history.

## What never goes on the shelf

- Anything built on funded client hours.
- Anything that names a client, a site, or a person.
